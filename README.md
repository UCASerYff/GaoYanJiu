# 搞研究 V4.02

独立 macOS 应用，包含本模块完整业务、游戏场景和 WidgetKit 小组件。运行不依赖搞七廿三或其他六个应用；联动功能需要同时安装相关应用。

## 下载与安装

从 [Releases](https://github.com/UCASerYff/GaoYanJiu/releases/latest) 下载 `GaoYanJiu-4.02.zip` 和同名 `.sha256` 文件。仓库保存源码，安装包作为 Release 附件单独发布。

1. 支持 macOS 14 或更高版本、Apple Silicon；暂未提供 Intel 版本。
2. 解压 ZIP，将 `搞研究.app` 拖入“应用程序”文件夹。
3. 如果 macOS 拦截打开，请先确认软件来源，再进入“系统设置 → 隐私与安全性”，允许该应用打开。发行包使用 Apple Development 签名，未做 Apple 公证。
4. 安装后运行一次，再从系统小组件列表添加本应用的小组件。整合版的小组件需要重新添加。

下载后可在文件所在目录运行 `shasum -a 256 -c GaoYanJiu-4.02.zip.sha256` 核验安装包。发行文件使用英文名称，便于命令行校验和下载。

## 功能

- 管理论文、成果、项目、经费、证书和投稿状态。
- 保存与打开 PDF 等研究附件，查看期刊指标。
- 三维浮空研究城：建筑、扩建与研究进度联动。

- 从菜单或 ⌘, 打开设置，提供外观、模块设置、备份与恢复。
- 提供本应用对应的桌面/通知中心小组件。

## 用户数据、附件与隐私

源码及安装包不包含个人记录、账户配置、账单、健康数据、私人附件、API 密钥、浏览器会话或用户备份。新电脑首次打开时创建自己的资料库；GitHub 下载不能恢复个人数据。

- 业务数据目录：`~/Library/Application Support/GaoSeries/Research/`。
- 数据库或小组件镜像：`~/Library/Group Containers/5G96498KGJ.com.academic-achievement.manager/`。
- 设置保存在本应用的 UserDefaults 域；凭据由 macOS 钥匙串管理，不导出到普通备份文件。
- 公开安装包会删除本机编译路径、源文件索引及扩展属性，再重新签名。签名证书的公开身份信息随软件发布，签名私钥不在仓库或安装包中。

真实业务历史完整保留。界面采用分页或归档减轻加载；游戏事件最多保留 300 条、抽取记录最多 200 条、词元账户显示采样最多 300 条，累计收益、余额、保底计数、库存与游戏进度独立保存。

## 数据迁移与恢复

V4.0 从整合版拆分时保留业务历史、余额、库存、游戏进度、设置和全部附件。独立应用继续使用各自的数据目录，升级或替换应用程序不会删除这些数据。

在设置的数据页导出“完整资料 ZIP 备份”。恢复备份可迁移本应用的资料、App Group 镜像、设置以及已管理的 PDF、Word、照片等附件。备份使用逐文件 SHA-256 校验与 SQLite WAL 一致快照，恢复前保存安全副本；待下次启动应用时应用恢复。备份必须来自同一应用，不能将另外一个模块的备份直接导入。钥匙串凭据需在新电脑重新配置。

迁移临时副本不属于程序运行依赖，确认数据与附件完整后可自行清理。个人备份应单独保管，不应放进源码目录或上传公开仓库。

## 从源码构建

需要完整 Xcode、Python 3 和 Apple Silicon Mac。默认脚本使用项目配置的开发签名身份；自行构建需使用自己的 Apple Development 证书，并相应调整签名团队、App Group 权限及小组件工程配置。

```sh
./scripts/build.sh
./scripts/package.sh
# 退出搞研究后，保存输出中的私有 backup 目录
python3 scripts/upgrade_data.py snapshot --version 4.02
./scripts/install.sh
# 启动新版检查记录、附件、研究城与系统小组件后，退出应用再核验
python3 scripts/upgrade_data.py verify-live /path/to/private/backup
# 完整回归测试套件
./scripts/test_import.sh
./scripts/test_exchange.sh
./scripts/test_exchange_clients.sh
./scripts/test_backup.sh
```

通过环境变量 `GAO_SIGNING_IDENTITY` 可指定签名证书。修改团队后也需调整 `scripts/install.sh` 中的团队检查。`dist/` 存放本地发行 ZIP 和校验文件，不提交到 Git；上传到 GitHub Releases。

- `Sources/`、`Shared/`（如有）与 `Module.swift`：业务和游戏逻辑。
- `GameWorld/` 与 `Resources/`：场景、模型、贴图和其他资源。
- `Host/`：独立入口、设置、完整备份和联动服务。
- `Widgets/`：小组件；`Tests/`：回归验证。

## 版本更新

版本以 `Info.plist` 为准。后续更新仅更新受影响的应用，每次版本 +0.01、构建号 +1。先核验用户资料，再安装新程序并检查记录、附件和游戏进度，成功后清理旧程序、安装包与中间构建。程序资源与用户资料须分别处理，不能用清理构建目录的方式删除用户数据。

第三方组件和资源保留各自许可，详情见 `Resources/` 中的许可、来源说明与补丁记录。

## V4.02 更新

1. **跨 App 资料交接协议（GaoAction V1）与包格式接入**：
   - 对外提供安全的 `research.importDocuments` 白名单动作，带有交互审核弹窗及目标文件夹选择，支持 `.gaoaction` 外部包导入。
   - 随应用发布能力声明 `GaoCapabilities.json`，严格限制输入载荷和参数白名单。
2. **联动「搞整理」（`files.choose`）**：
   - 支持从资料库文件夹工具栏的“资料交接 → 从搞整理选择资料…”发起选定导入，按用户在搞整理中实际选定的文件复制入库并去重、生成摘要与索引，不盲目全量静默导入。
3. **联动「搞截图」（`ocr.files`）**：
   - 支持对扫描 PDF 或图片资料一键送搞截图进行文字识别（OCR）。原附件完整保留，OCR 识别产物通过 `DocumentProvenance` 和衍生版本记录关联，全文索引同步更新并标明来源与置信度。
4. **联动「搞文件」（`documents.open`）**：
   - 支持在搞文件中外部打开和编辑研究资料。编辑完成后支持“替换为新版本（保留历史摘要）”或“另存为新附件”，严密校验 SHA-256 和版本历史。
5. **事务性导入日志与恢复机制（`ResearchImportJournal`）**：
   - 采用 staging 安全隔离与原子性校验，支持 SHA-256 去重与幂等处理，实现崩溃及进程中断后的安全恢复与附件/数据库补偿，杜绝孤立附件与脏数据。

## V4.01 更新

修复从整合版拆分后小组件不出现在列表的问题：系统仍登记已删除的 V4.6 搞研究宿主，导致 WidgetKit 忽略独立版扩展。安装时精确注销本应用已失效的旧宿主登记，再注册、启用新扩展；失败时恢复旧程序与插件登记。构建保留 Xcode 生成的扩展元数据，并核验标准扩展入口、签名、应用与小组件版本一致。

增加私有升级备份与核验工具：逐文件 SHA-256、SQLite WAL 一致快照、业务记录与研究城状态对比、附件引用和文件完整性检查。V4.0 → V4.01 资料格式未变，沿用原数据路径；原系统钥匙串凭据继续使用。私有备份保存在 `~/Library/Application Support/GaoSeries/UpgradeBackups/Research/`，不提交到仓库。核验工具严格报告新增、删除和修改；首次启动产生的每日自动备份也会列为差异，须核实新增备份并保留轮换前的旧备份，不能忽略业务或附件差异。核验成功后清理旧程序、旧安装包与中间构建，保留个人资料及备份。

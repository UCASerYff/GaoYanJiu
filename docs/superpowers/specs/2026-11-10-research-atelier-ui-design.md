# 搞研究 4.13「学术工作室」界面设计

日期：2026-11-10
状态：用户已确认视觉方向与功能方案

## 目标

将搞研究改为具有纸张、书卷与安静工作台气质的独立 macOS 界面，不再沿用其他搞系列应用的视觉规范。同时收拢导航：删除资金栏目，把状态更新、已归档和投稿门户统一并入在投管理。

本轮只改变界面组织、视觉和相应导航状态，不改变论文、成果、项目、资料、证书、研究城、附件、备份、交接和小组件的业务语义。

## 视觉系统

- 浅色模式使用米白画布、深墨绿主色和陶土色提醒色；深色模式使用暖炭色画布、低饱和浅绿主色和柔和陶土色，避免简单反色。
- 页面标题采用 macOS 可用的宋体类字体，正文、数字与操作控件继续使用系统字体，保证中英文和数字清晰可读。
- 卡片使用细边框、轻阴影和连续圆角；不使用大面积高饱和渐变或过度玻璃拟态。
- 侧栏约 248 点宽，分为「研究工作台」「资料与资产」「探索」。研究工作台包含在投、成果和项目；资料与资产包含实验数据、总结报告、重要文献和证书；探索包含研究城。
- 上下文搜索从侧栏移到主内容标题区，保留 ⌘F、清空搜索和按模块变化的提示语。
- 所有模块共享颜色、间距、卡片、页头和空状态样式；研究城只调整承载容器，不改游戏规则或场景逻辑。

## 在投管理

### 页签

在投管理内部提供「全部」「状态更新」「已归档」三个页签，并显示对应数量。侧栏不再出现状态更新和已归档。

新增独立的投稿范围状态 `SubmissionScope`，与模块导航 `LibraryFilter` 分离。论文查询按模块和投稿范围组合筛选，搜索语义不变。旧场景存储若停留在 changed 或 hidden，首次显示时映射到在投管理及相应页签；此后只保存新的模块与页签状态。

### 投稿门户

投稿门户不再是侧栏独立分组。宽窗口下，在投页右侧显示门户面板；窗口不足时，门户收进在投页工具区的「门户」按钮，以弹层或侧栏呈现，不挤压论文列表。

门户面板保留：门户名称与地址、同步健康状态、最近检查状态、重新打开登录窗口、新增门户、刷新和删除。删除仍使用原确认流程并保留论文；凭据继续使用原钥匙串服务，不进入网页、源码或备份明文。

### 既有功能

保留添加在投、手动添加、从投稿系统导入、刷新全部、统计与趋势、论文卡片、拖拽排序、详情、标记已读、归档、恢复追踪、删除和回收站。状态更新数量仍由原业务字段计算，归档仍使用原 hidden 字段，不迁移论文记录。

## 资金栏目与历史数据

删除资金导航项、资金仪表盘、资金搜索提示和相关新建菜单分支，移除不再使用的资金界面实现。搞研究中不出现资金栏目或资金页面。

`FundingRecord`、原资料字段、回收站记录、备份和迁移逻辑继续作为只读兼容依据保留，不能为移除界面而删除用户历史。旧 `gaoyanjiu://funding` 深链继续转交搞积蓄，不打开搞研究资金界面。

## 组件与数据流

- `ContentView` 负责模块导航、在投页签、搜索和门户显示状态。
- 可复用工作区页头、导航行、卡片和门户面板承接新视觉，避免在各业务页面复制颜色与布局常量。
- `PaperStore` 继续作为唯一业务数据源；页签只是查询条件，不复制论文数组，不建立第二套持久数据。
- 各编辑器、详情页、交接审核和错误提示沿用原环境对象与原状态机。
- 资料加载失败、磁盘版本冲突、附件缺失、门户错误和刷新失败继续使用原保护行为；新布局不能吞掉错误或将失败显示为成功。

## 兼容、错误处理与可访问性

- 资料格式保持 schema32，沿用 `~/Library/Application Support/GaoSeries/Research/`、App Group、UserDefaults 域和钥匙串服务。
- 不新增数据迁移；仅迁移界面场景状态。无法识别的旧模块值回退到在投管理的全部页签，不影响业务资料。
- 最小窗口仍为 1040×720；在窄宽度下优先收起门户面板，再压缩非关键说明，论文标题和主要操作保持可用。
- 所有图标按钮保留辅助功能标签、帮助文本和键盘快捷键；颜色不是状态的唯一表达方式。

# 搞研究 Windows V4.15

适用于 Windows 10 和 11 x64。Windows 构建号为 7，命令行报告 4.15+7。安装包由 Windows Installer 管理，包含界面和命令行程序。

## 安装与资料

1. 从发布页下载 `GaoYanJiu-Windows-4.15-build7-x64.msi` 及同名 `.sha256` 文件。
2. 在 PowerShell 中计算 SHA-256，与校验文件中的值比较。安装包没有 Authenticode 签名。
3. 退出旧版搞研究，在当前 Windows 用户下双击 MSI，完成后从开始菜单打开「搞研究」。默认安装目录为 `%LOCALAPPDATA%\GaoYanJiu\`。

```powershell
Get-FileHash -Algorithm SHA256 .\GaoYanJiu-Windows-4.15-build7-x64.msi
Get-Content .\GaoYanJiu-Windows-4.15-build7-x64.msi.sha256
```

旧版 Windows 资料继续使用 `%APPDATA%\GaoSeries\Research\AcademicAchievementManager\`。首次使用时需确认创建资料库。若资料确实存在但缺失、损坏或版本不受支持，界面会报告原因并保护原文件。卸载 MSI 保留资料。旧便携版的程序文件可以在验证新版本后自行移除。

`library.json` 沿用 schema 32，保留扩展字段、历史项目、历史资金、回收站、附件与研究城状态。V4.14 工作区已移除项目管理和资金栏目。Windows 凭据由本机 DPAPI 加密，保存在资料目录的 `secrets\`。应用通过本机回环访问界面及资料，常规入口使用 Edge 应用窗口，Edge 不可用时用系统浏览器打开。

## 通知区域

正常启动后，任务栏通知区域显示搞研究图标。Windows 也可能把图标放在隐藏图标菜单里。关闭工作台会保留后台与提醒，点图标或选择「打开 搞研究」可恢复。设置里的「退出搞研究」和托盘里的「退出」都会先确认，再关闭工作台、投稿门户和同一资料目录的小组件。选择取消可以返回并保存未提交的改动。

工作台使用独立的临时 Edge 资料目录。成果和投稿等外部链接交给系统浏览器。搞研究退出后，系统浏览器继续运行。若工作台本身使用系统浏览器作为备用入口，对应标签页会显示退出状态。

## 工作流

| 页面 | 可用操作 |
| --- | --- |
| 在投管理 | 直接添加稿件和更新状态，按有更新、待跟进、归档和投稿状态筛选。宽窗口右侧显示最近进度、稿件预览和门户。窄窗口通过工具栏打开门户，点稿件标题查看详情 |
| 稿件下一步 | 在活跃稿件详情设置具体行动和日期。从在投页的集中清单访问逾期、今天、未来七天和更晚的事项，可回到稿件状态时间线。由用户标记行动完成，稿件状态变化和系统待跟进设置各自保留 |
| 投稿门户 | 在工作台的投稿门户打开内嵌 WebView2，登录后主动提取当前稿件，回工作台逐项审核导入。多门户可按顺序刷新 |
| 待跟进提醒 | 在设置中启用 Windows 系统提醒并设定天数。系统对活跃稿件的同一状态阶段去重，点击打开对应稿件 |
| 成果管理 | 默认显示成果清单，按需切换统计。维护成果类型、专利子类、署名、日期、编号、链接和 PDF/图片附件 |
| 刊物指标 | 成果编辑器通过 Crossref 推荐刊名和 ISSN。输入 EasyScholar 密钥后可查询并随成果保存指标 |
| 实验数据、总结报告、重要文献 | 并列查看文件夹和文件清单，窄窗在两者之间切换。支持标签、排序、拖放与批量上传、去重、文件名及全文搜索、PDF/图片和索引文本预览、下载、编辑和回收站 |
| 证书 | 名称、日期、标签、附件、可排序记录表、年度及标签图表 |
| 研究城 | 三维场景、镜头控制、地块和库存集中在建造工作台。支持放置、移动、收回、相邻扩建、祈愿、库存、金币、票券和历史 |
| 桌面小组件 | 从开始菜单打开「搞研究 - 在投状态持续时间」或「搞研究 - 成果与署名分布」。两者使用同一资料库的本地统计快照，点击可定位到主界面 |

全文索引支持常见文本、DOCX/PPTX/XLSX，以及含文字层的 PDF（最大 128 MiB，每份最多索引前 300 页）。扫描件可以送搞操作识别。浏览器单次上传限制为 256 MiB，需要导入更大的单个资料文件时可在文件夹的资料交接菜单中指定本机路径。

内嵌投稿门户使用微软 WebView2 Evergreen Runtime。各门户使用资料目录下的独立 WebView2 资料夹，登录由用户在门户窗口完成。应用从当前页面提取稿件所需字段，待审核后才写入资料库。缺少 WebView2 Runtime 时可使用外部浏览器捕获。

系统提醒默认关闭。启用后，运行中的搞研究按本地时间 09:00 处理到期事项，并发往 Windows 通知中心。关闭工作台窗口可以保留应用会话。完全退出期间到期的既有计划会在下次打开时补发。归档、终态和删除会撤下对应的提醒。投递受系统通知设置影响。显式指定的隔离资料目录仍提供应用内待跟进提示。

### 跨应用交接

- 在研究资料条目的操作菜单中选择「送搞操作识别文字（OCR）」。配套版本的搞操作经用户审核、识别并完成导出后，可通过当前用户的固定回传目录交回结果。原资料条目和侧栏「OCR 待审核」均可打开复核，查看原件、页码和识别文字。确认应用后，派生件才归档和建立索引，原件及页码关联保留。
- 无法自动回传时，可在搞操作导出 `OCR-<UUID>.gaoaction`，再从「资料交接与回执」在结果有效期内手动接收。自动回传请求的有效期沿用 GaoAction V1。已安全收到的自动回传可稍后审核。
- 「从搞文件选择资料」使用 GaoAction V1 文件选择。编辑流程会给搞文件发送副本，用户可把编辑结果回导为同一资料的新版本或关联附件。也可审核从搞文件直接收到的资料并导出回执。
- 已安装的同伴应用可通过能力查询及交接启动参数接入。若同伴不可用或其版本不提供相应启动入口，应用会保留端到端交接包供手动打开。Windows 版同时识别旧 Windows 搞文件的历史收件方标识；新交接使用 `com.academic-achievement.manager`。
- 搞文件 V1.11+2 安装版支持自动打开搞研究签发的回执。来自搞研究的选件和编辑请求需要搞文件提供带审核的 GaoAction 启动入口。

## V4.15 更新

Windows Build 7 为任务栏、开始菜单和通知区域提供同源多分辨率圆角图标。托盘按任务栏所在显示器的 DPI 选择图标，工作台窗口沿用现有开始菜单快捷方式的应用标识。投稿门户可随窗口所在显示器更新大小图标。

成果分类图的各行共用类别、绘图区和数量列。长名称可以换行。窄窗中，名称和数量仍在同一个行组内，柱占用行组的完整宽度。

## V4.14 验收记录

- 在 Windows 11 x64 用隔离资料验收。七页覆盖浅色和深色，高缩放覆盖 175% 及 150% 窄窗。还检查了长稿名、真实状态变化、设置、加载、错误恢复和通知深链。Windows 10 实机留待复核。
- Windows Installer 用隔离的 MSI 标识验证 4.14+4 到 4.14+5 原位升级和卸载，并前后核对资料、附件和正式安装。
- 用真实 Windows 通知区域接口验证图标添加、更新和移除。向隔离窗口发送任务栏创建消息验证恢复。最终打包程序在独立 Windows 桌面上验证关窗留驻、普通入口立即重开和退出后的端口清理。另以独立 Edge 进程核对退出范围，并验证取消退出、保存和深链转发。
- 内嵌投稿门户使用 150% Windows 显示缩放下的合成站点验收，覆盖登录子窗口、主动提取和逐项审核。真实出版商登录和 EasyScholar 密钥尚未验收。
- 使用独立 Windows 通知标识和合成稿件验证投递、重启去重和归档后撤回。测试关闭了通知横幅，通知深链通过无头工作台验证。
- 研究城复用原始天空、草地、岩石贴图和原目录标识。建筑与地形用 Canvas 三维几何重建，SceneKit 材质、阴影和部分模型细节有差异。
- 桌面小组件以独立 Windows 小窗运行，保留统计和链接。Windows 11 Widgets 面板无系统注册。
- 本构建使用合成资料验证 NTFS 回传路径、摘要与页码绑定、可重查的待审核状态和确认后索引。联调使用搞操作当前源码及 Windows 原生 OCR 识别合成数字图片，并核对实际导出、回传和三种派生文件。配套安装版的联调沿用历史验收记录。

## 构建与复现

在 Windows x64 上使用干净的 CPython 3.12 环境运行以下命令。正常构建会安装开发依赖、运行回归并输出 MSI 及 SHA-256 到 `windows/dist/`。构建时可通过 `-DistributionDirectory` 写入候选目录。空白用户环境可用 `smoke_install.py --upgrade-from` 验证 MSI 升级和资料兼容性。已有正式安装的用户环境可再加 `--isolate-msi-identity`，使用测试专用的 MSI 标识、注册表键和合成资料验证同样的升级步骤。GitHub Actions 上传 Windows 构建产物。

```powershell
pwsh -File .\windows\build.ps1 -Python C:\path\to\venv\Scripts\python.exe
python .\windows\tests\smoke_install.py .\windows\dist\GaoYanJiu-Windows-4.15-build7-x64.msi
node .\windows\tests\smoke_browser.mjs "C:\Program Files\Google\Chrome\Application\chrome.exe" C:\path\to\venv\Scripts\python.exe
```

在有 Explorer 通知区域的 Windows 会话中，将 `GAO_RESEARCH_NATIVE_TRAY_TEST` 设为 `1`，可用 `python -m pytest windows/tests/test_windows_tray.py` 复现原生托盘回归。

`GaoYanJiu-cli.exe` 支持 `--version`、`--inspect`、`--create-empty`、`--widget-snapshot`、`--widget submissions|works` 和 `--capabilities`。可用 `--data-dir` 或 `GAO_RESEARCH_DATA_DIR` 指定隔离资料。`--gaoaction PATH` 打开待审交接。`gaoyanjiu://submissions` 和 `gaoyanjiu://works` 定位页面，`gaoyanjiu://widget` 打开桌面组件。
